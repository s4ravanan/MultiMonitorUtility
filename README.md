# MultiMonitorUtility

A Windows desktop utility for improving multi-monitor workflows.

## Purpose

This project explores a lightweight alternative to heavyweight multi-monitor utilities by building focused Windows features with a native WPF application.

The current implementation is intentionally small and serves as a foundation for adding monitor-aware desktop functionality.

## Technology

- C#
- .NET
- WPF
- Windows APIs
- Multi-monitor desktop management

## Current Status

Early-stage project under active development.

The initial implementation establishes the WPF application structure and the foundation for monitor-aware functionality.

## Planned Areas

- Per-monitor desktop utilities
- Multi-monitor taskbar / desktop controls
- Monitor-aware window management
- Lock-screen / wallpaper coordination
- Configuration and persistence
- Lightweight background operation
- Windows startup integration

## Development

Build:

```bash
dotnet build
```

Run:

```bash
dotnet run
```

## Engineering Notes

The project is intended as a practical exploration of Windows desktop development, multi-monitor APIs, and building small native utilities with .NET.

More documentation will be added as individual capabilities mature.
